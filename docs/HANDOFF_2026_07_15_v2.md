## Gotchas

- WSL cross-filesystem Edit tool (Windows \wsl.localhost\... paths) can
  silently fail to persist writes -- always verify with a WSL-native
  grep/cat after, or write via a WSL-native Python script instead.
- Running standalone test/bench scripts on the SAME GPU as a live training
  job can starve it (dxgk ENOMEM) and kill the run -- use the idle GPU, or
  wait, for any concurrent-with-training experimentation.
- `pgrep -af <pattern>` can match its own invocation string as a false
  positive when the pattern text appears in the searching command line --
  confirm with `ps -p <pid>` before trusting a match.

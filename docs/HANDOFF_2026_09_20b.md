## Gotchas
- The 5090's quoted "209.5 TFLOPS BF16" is the FP16-**accumulate** figure; training uses FP32 accumulate → ~104.8. Using 209.5 halves apparent MFU.
- `mfu_report.py` per-module shares are inflated ~2.07× (FlopCounterMode attributes ops to a module and its ancestors); the printed inflation factor converts them to true fractions. `get_total_flops()` is exact.
- Inline `for` loops, `$vars` and redirects inside a `wsl.exe bash -lc "..."` string get mangled — write a `.sh` file. Bit me three times today.
- `pkill -f <pattern>` self-matches the wsl.exe command line and kills the launcher; use `pgrep -f "[p]attern"` or kill by PID.
- Never edit a shell script while bash is executing it (lazy byte-offset reads) — copy to `temp/.run_*_active.sh` and run the copy.
- `gate_rank > 0` changes param-group shapes → NOT resume-compatible with an existing checkpoint; fresh runs only.

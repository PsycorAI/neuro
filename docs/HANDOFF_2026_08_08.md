## Gotchas

- **`timeout --signal=INT -k <n>` needs `-k 300`, not `-k 60`**, for any run with a synchronous final-checkpoint + eval/energy-report path. `-k 60` SIGKILLed two real runs this session — see `reference_wsl_background_launch.md`.
- **Relaunching a config with the same `run_name` auto-resumes** from its latest checkpoint (`src/train_gpu.py` glob on `step_*.pt`) — don't assume a restart starts from scratch.
- **Complex inline `wsl.exe -- bash -c "..."` commands silently mangle** `$VAR`/quoting under this harness — write a real `.sh` file instead, every time. See `reference_wsl_background_launch.md` (3rd gotcha).
- `blk5`/`blk7` decay-gate saturation is elevated (~16-17%) in p4_seed1's latest evals — well under the 20%×2-eval watchdog threshold and not growing, but worth a glance when reviewing the final numbers.

## Gotchas
- A CUDA graph's input tensors must stay referenced after capture (a freed arange gave an index_copy_ assert on replay).
- torch.compile + in-place write into a VIEW of one big tensor clones the whole base per call.
- `torch.tensor(list, device=cuda)` syncs the stream; use `fill_` in per-token paths.
- Dynamo reuses a compiled body across instances of the same method in one process (two variants in one test = one compile).
- bash re-reads a running script: edit only lines after its current position, or not at all.
- v4 is float-chaotic: compare paths with paired CIs + the full forward + a control; one text's starts = one sample.

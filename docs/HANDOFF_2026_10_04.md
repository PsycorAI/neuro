## Gotchas
- **G3-shape runs don't fit the 5080** (16 GB); the gap-MQAR arms spill. Use it only for 30M runs.
- **Gap-MQAR at 150M** needs `mqar_pad_to 65` + `mqar_gap_pad_to 512` + `mqar_batch 8`. Padding everything to 512 spilled at 31.8 GB.
- **Gap-MQAR with compile also needs `mqar_compile_static: true` + `gdn2_cumsum_eager_max_b: 8`.**
  - Without them, r21c crashed at ~70%: the Inductor SplitScan bug on the GDN-2 cumsum, hit by the batch-8 × 512 gap batches.
  - Both flags are exact math. The v4 config needs them too.
- **After any trainer edit, run the CPU smoke** `temp/smoke_r19_cpu.py` before queued runs start (`feedback_smoke_before_queue.md`).
- **Lock-holding queues:** spawning `setsid` children leaks the lock fd (`reference_flock_fd_inherit.md`).
- **`pkill -f` inside `wsl bash -lc`** can match its own shell. Kill by PID.
- The SFT/scorecard scripts know `SparseAct` (`interp_scorecard.py` updated); other eval scripts are untested with it.

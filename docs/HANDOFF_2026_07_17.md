## Gotchas

- **`reduce-overhead` compile mode WILL crash** on this training loop
  (`grad_accum` + checkpoint-recompute + CUDA Graphs, open upstream PyTorch
  bug). Never use it here — `default` mode only.
- **Long silent compile (~13min, 0% GPU util) at 500M scale is normal**, not
  a hang — check `ps -o pcpu,stat` for high CPU (tracing) vs near-0% (stuck)
  before killing anything.
- **Launching a long background job via `wsl -e bash -c "cmd & disown"` from
  PowerShell does NOT survive** — use a tool call whose own backgrounding
  wraps `wsl -e bash -c "cmd"` directly (no internal `&`).
- Windows/WDDM shared-GPU-memory spillover near the 32GB ceiling silently
  drops throughput with no error — check Task Manager's GPU panel, not just
  `nvidia-smi`, when batch-sizing at the edge.

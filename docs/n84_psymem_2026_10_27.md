# Psymem (codename): synaptic memory + diary as the product (brainstorm, 2026-10-27)

Status: **BRAINSTORM / proposed**. Nothing is built. Glenn's Q23–Q30 (follow-on to `n84_psyfile_design_2026_10_27.md`).

## 1. The idea in one line

The **synapses are the memory's index and its web of relations**, and the **diary is the content**. This is the brain's own
split, from hippocampal indexing theory (Teyler & DiScenna 1986): the hippocampus does not store the memory itself. It stores
a synaptic *index* that re-activates the cortex where the content lives. HippoRAG uses the same theory, but with an
LLM-built graph and PageRank instead of real synapses.

- **Synaptic layer:** a fixed-size, spiking, plastic synapse matrix (1-bit Willshaw-style, or a delta-rule matrix).
  - It maps **cue → diary address** (hetero-association) and **span ↔ span** (links between things recalled together).
  - Writes happen in one shot. Strengths change with use (recall strengthens, disuse weakens). Dreaming adds links.
- **Diary:** exact text, append-only, the master copy (it is what makes migration and forgetting lossless).
- **Psymem encoder:** a small spiking encoder that belongs to the file spec (versioned).
  - It turns text into sparse spike codes, so the synapses do not depend on whichever model or agent is asking.
  - Upgrading the encoder = replay the diary into new synapses.

**API (MCP server + Python/JS SDK)**, so any model or agent can use it:

| Call | What it does |
|---|---|
| `remember(text)` | Write to the diary and the synapses |
| `recall(cue)` | Quoted spans with dates and strengths |
| `associate(span)` | Linked spans, found by spreading activation |
| `dream()` | Consolidate the memory |
| `forget(span)` | Delete, and return a receipt |
| `explain(answer)` | Which synapses fired |
| `quiz()` | Run the recall contract |

The host model only ever sees text, so Claude, GPT, local models and our own Neuro all work with it.

**VISION:** this puts the plastic synapses at the core of the product. Contrast v4, where the plastic part is 7.6% of
parameters and recall rode on the HOLA cache. **Drift risk:** if the synaptic index loses to plain vector search and we
quietly fall back to embeddings, that is drift. Flag it the moment it happens.

**Honest status:** our only synaptic test so far failed. v4's Hebbian M recalled 0/5 held-out facts (n84 brain test).
Cue → address is an easier job than cue → generated answer, and associative memories do it well on paper, but it is
unproven here.

## 2. Is it better? (Q24) — the honest scorecard

| Axis | Synaptic index + diary | Plain vector search + text | Verdict |
|---|---|---|---|
| Speed | Add ~16 bit-rows per cue: microseconds, fixed cost, no re-indexing | ~1 ms at personal scale | Real but small; matters on phone / neuromorphic chips |
| Size | Synapses fixed size: 4,096² × 1 bit = 2 MB. On paper ~0.69 bit/synapse max (Willshaw 1969) ≈ 10–30k cue→span links per 2 MB at ~16 active of 4,096 | ~1.5 KB/chunk fp32 (384-d); 100k chunks ≈ 150 MB (≈ 38 MB int8) | Synapses smaller but capped; roll volumes |
| Energy | Accumulate-only (no multiplies), sparse | Dot products over all or ANN-probed vectors | Big ratio, tiny absolute: retrieval ≪ LLM energy. Matters on edge only |
| Quality (exact) | Exactness comes from diary quotes; synapses can mis-link (interference) | Exact retrieval good | Must measure; LoCoMo / LongMemEval near ceiling (92–97% vendor self-reports) |
| Relations | Links form automatically by co-activation; multi-hop by spreading activation; strength = use history | Needs a separate graph (Zep, Cognee, HippoRAG) | **Main real advantage**, but HeLa-Mem (ACL 2026) already does Hebbian graph memory |
| Learning from use | Built in (spaced strengthening, decay, dreaming) | Static unless rebuilt | Advantage |
| Ownership / portability | One file; diary migrates losslessly; forgetting receipts | Vendor DB, or ad-hoc exports | Advantage (also a compliance feature) |

## 3. Intelligence inside the memory (Q25)

- **Search:** cue → spreading activation → ranked, quoted spans. This finds things by association, not only by similarity.
- **Summaries:** dreaming writes *gist* entries (like hippocampus → cortex consolidation). Each gist links to its source
  spans, so it can always be checked and quoted.
- **Data mining:**
  - hubs (what you talk about most);
  - trends over time;
  - **contradictions** (two strongly linked spans that disagree → flag);
  - gaps (quiz failures).
- **Dreaming builds connections:**
  - replay salient spans in random pairs and sequences;
  - strengthen links that co-activate above threshold;
  - downscale and prune weak synapses (the synaptic homeostasis idea of sleep, Tononi & Cirelli);
  - the quiz gates every change (do no harm).
- **Who does the "thinking":** the synapses do association. A small local Neuro model writes gists and cue questions.
  Everything model-written stays linked to diary quotes.
- **Prior art to credit:**
  - Letta sleep-time compute (2025, LLM rewrites memory while idle);
  - HeLa-Mem "Hebbian Distillation" (2026);
  - A-MEM (links), Zep / Graphiti (temporal graph), HippoRAG.
- **Our difference:** real plastic synapses instead of prompts and graph databases, plus the diary, quiz and receipts contract.

## 4. Many sessions in one memory (Q26)

- **Yes.** One Psymem file = a lifetime.
  - The diary is append-only, with one chapter per session.
  - The synapses are shared across sessions.
- **Volumes roll** when the quiz shows interference (old-item recall drops below a threshold, e.g. 90%) or at a size cap.
  - Old volumes stay searchable (diary text + frozen synapses).
  - Dreaming carries the gist and the strongest links forward.
- **Sizes:**
  - Heavy user ≈ 20k tokens/day ≈ 7M tokens/yr ≈ ~10 MB compressed text/yr.
  - Plus a few synaptic volumes of 2–16 MB each.
  - Years fit on a phone.

## 5. Business (Q27–Q30) — brainstorm

**Market facts (searched 10-27):**
- Mem0 raised $24M (seed + Series A, Oct 2025; third-party estimated valuation ~$150M). Supermemory raised $2.6M seed.
- Crowded field: Mem0, Zep, Letta, Supermemory, Mastra, ByteRover, Agent Zero Memory, Memanto, MemOS, Cognee, PowerMem.
  The frontier labs also ship built-in memory for free (ChatGPT, Claude, Gemini).
- Benchmarks are near ceiling: vendor self-reported LoCoMo ~92–96%, LongMemEval ~94–97%, and the metrics differ.
  The less saturated one is BEAM at 1M / 10M tokens (Mem0 self-reports 64.1 / 48.6).
- Brain-inspired hardware is getting funded (Unconventional AI $475M seed; CyberSwarm $50M Series A, aggregator-reported;
  Innatera EIC €15M). Those chips need killer apps; a synaptic memory is a natural one.
- Name: "PsyMem" is already a 2026 paper (TACL / ACL 2026, role-play memory). Fine as a codename; check before public use.

**For the shift:**
- It is the purest form of the vision (synapses that learn and remember).
- It does not need to win the model race.
- It is model-agnostic, so the market is every agent.
- It is cheap to build (CPU / one GPU).
- MCP gives instant distribution.
- Ownership, forgetting receipts and audit fit privacy laws and enterprises.

**Against:**
- Crowded, fast-moving, and well funded.
- "Neuromorphic" alone does not sell. Developers buy accuracy, latency, price, privacy and ease.
- Accuracy is near ceiling on the standard benchmarks, so it cannot be the wedge.
- The core (synaptic recall) is unproven here.
- The Hebbian-links idea alone is already published (HeLa-Mem).

**Proposed staged pivot (if Glenn agrees):**

1. **Proof, 2–3 weeks, no cloud spend.** Psymem v0 on CPU / 5080:
   - diary + 1-bit spiking synaptic index + spreading activation + dreaming link-builder + quiz;
   - wrapped as an MCP server.
2. **Go / kill tests:**
   - Gate: within a few points of a BM25 + vector baseline on LoCoMo / LongMemEval with fewer tokens.
   - **And** a clear win on at least one of:
     - (a) multi-hop / relations;
     - (b) recall improves with use, with forgetting receipts that pass;
     - (c) BEAM-1M scale;
     - (d) size / latency / energy on a laptop or phone.
   - If no win: Psyfile v2 (diary + quiz + receipts) is still a sound, honest product, just less unique.
3. **If go:**
   - open-source the format + SDK + MCP server;
   - a live "watch your memory grow synapses" explorer (the viral piece);
   - honest benchmark + disclosures.
4. **Money:** open core.
   - Paid: hosted sync / backup across devices; team / enterprise (audit, provable forgetting).
   - Licensing: neuromorphic chip makers, device makers, game studios (NPC memory).
5. **Models:**
   - finish the runs already paid for, then stop large pretraining spend;
   - keep a small spiking Neuro as the native Psymem engine (encoder + dreaming model), phone-sized.
6. **Raise after traction** (users, stars, a published result), not before.

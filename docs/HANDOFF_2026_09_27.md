## Gotchas
- Never write repo files with Windows Python's default newline (it produced CRLF in `to-do.html` once). Use `newline=''`.
- `pkill -f <pat>` inside `wsl.exe bash -lc` kills its own shell; use `[x]yz` patterns. `$` and awk quoting get mangled, so put logic in `.sh` files.
- Compiled max-autotune runs aren't run-to-run deterministic. Use 30M eager for bit-identity checks.
- Don't benchmark on a GPU while a timing run uses it. 5080 throughput is noisy (±15%) while the 5090 runs a job.
- The no-sync FPT patch `temp/apply_fpt_nosync.py` is NOT applied, and it's moot if v4 uses lif_exact.

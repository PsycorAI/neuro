## Gotchas

- **5080 is unreliable for anything near ~20GB+** — not just throughput contention from Glenn's 3D
  sim, but genuine WDDM spillover: `torch.cuda.max_memory_allocated()` reported 27-29GB "allocated"
  on a 15.92GB card before finally hard-failing. Treat any 5080 memory number above ~14GB as
  already-spilled and untrustworthy; use the 5090 for anything near its real capacity.
- `_gdn2_dense_chunk`'s ragged-tail branch (`src/delta_chunked.py` ~line 397) is NOT fixed at the
  kernel level — only worked around by keeping `gdn2_chunk_size` at values that stay chunk-aligned
  for realistic sequence lengths. If a future config raises it again, re-read this gotcha first.
- `configs/x2_hygiene.yaml` / `temp/chain_x2_after_x1.sh` exist (built, queued, killed) — their
  `gdn2_chunk_size: 256` is now stale/wrong if ever relaunched; would need updating to 64 first.

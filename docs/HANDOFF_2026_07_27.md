## Recent findings & pointers

- **SimPO fails at 500M scale, twice** — v3 (β=2.0) word-salad collapse by
  37% through budget; v3b (β=0.4) subtler repetition-lock by 55% through,
  invisible to loss/accuracy metrics. Reverted to standard DPO (β=0.1).
  Details: `neuro_simpo_collapse_2026_07_26.md`, journey.html §46.
- **Calibration methodology for gen-check text** — always greedy-decode a
  known-undamaged baseline under identical settings before concluding
  collapse; small-model+greedy repetition alone isn't diagnostic. Same memory
  file, "General technique" bullet.
- **`gen_check()` landed as a permanent safeguard** in `train_sft.py` (shared
  by `train_dpo.py`) — prints greedy-decoded text every `gen_check_every`
  steps, ~0.8% overhead. Enable it on any future preference-optimization run.
- **Sparsity refine ratio bug** — matched absolute λ=3.0 from a 30M screen
  instead of the screen's actual 6× multiplier (pretrain λ had been bumped
  mid-run 0.5→1.0), undercompressed 22% vs predicted 45-54%. Corrected pass
  (λ=6.0) staged in `sparsity_cleanup_500m_v3.yaml`. Details:
  `neuro_sparsity_refine_ratio_gotcha.md`.
- **30M screens that shaped the pipeline**: sparsity elasticity (λ=3.0 sweet
  spot), curriculum warmup (dead heat, closed), LoRA-SFT capacity+budget
  (plateaus at loss ~4.2 vs full-FT's 2.68 — full-FT adopted; LoRA retest at
  500M still open). Details: `neuro_lora_at_30m_plateau.md`, journey.html §46.

## Gotchas

- **WSL can silently auto-upgrade and kill all running processes** with zero
  warning — happened mid-chain 2026-07-26. Recovery relies on the trainer's
  own checkpoint auto-resume; verify it actually works before trusting a
  long unattended run. `train_dpo.py` does NOT currently have this (see
  Immediate next action above). Details: `reference_wsl_auto_upgrade_kill.md`.
- **`train_dpo.py` always restarts fresh** from `dpo_init`, ignoring any
  existing checkpoints in its own run dir — do not assume DPO runs are
  resumable until the fix above lands.

## Gotchas

- **Any run with `gdn2_gate_norm: true` MUST use batch ≤16 with grad_accum**, not batch 28. Gate-norm's activation memory (3 RMSNorms × d_mem × 7 spiking blocks) pushes batch 28 past dedicated VRAM into WDDM spill, and the residency layer hard-fails at ~step 2500 with `dxgkio_make_resident: Ioctl failed: -12` — clean SIGKILL, no Python traceback. Signature = throughput collapse (9k→1.1k tok/s) preceding the kill. Batch 16/ga2 = 20.3 GB reserved with 12 GB headroom.
- **Running two 276M compiled runs simultaneously blows the WSL 24 GB RAM cap** during the compile-time peak — separate incident, killed arm A on 5090. Serialize heavy runs unless `.wslconfig` is raised.
- **Muon weight decay applies to BOTH optimizers now.** Any config that sets `weight_decay` was previously AdamW-only; now it decays 2D Muon weights too. The active configs all default to 0.0 so behavior is unchanged unless opted in.
- **`W_beta`/`W_alpha` are dead code under `decay_gate + gdn2_enabled`** — they're instantiated but receive zero gradient (replaced by `W_b`/`W_w`/`W_fdecay`). Do NOT diagnose gate behavior by looking at their weights — cost me 30 min. Look at `W_w`/`W_b`/`W_fdecay` instead.

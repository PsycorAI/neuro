How it works
Every memory is a neuron. Writing a memory wires it to the neurons that fired: one neuron per word, plus a sparse set of “meaning” neurons (4,096 of 65,536 win). That is a Hebbian update: no language model, no index rebuild.
Recall is one wave of spikes. The question fires its own word and meaning neurons; their synapses push activity into the memories they touch. The memories that receive the most drive win.
Time cells and who cells gate that drive: “last week” lights the days it means, a named person keeps their own memories bright. Neighbouring turns of a chat support each other.
It learns from use. Confirming an answer grows new synapses from that question’s neurons to the memory, so the same and similar questions find it faster next time.
One file you own. The diary and all its synapses live in one .plasmem file, on your machine.
Measured on benchmarks (not live): LoCoMo top-10 recall 76.7 for Plasmem vs 64.6 for keyword + vector search; one correction lifts recall of paraphrased questions from 57 to 89. Tour questions are chosen examples on this diary, not a score. Confidence (match coverage × share of the question’s words that have a neuron) is experimental: it separates answerable from unanswerable questions only partly (benchmark AUROC 60 on LoCoMo, 73 on LongMemEval).

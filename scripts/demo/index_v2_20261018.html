Per word, every layer is counted. Event-driven: a silent neuron costs nothing downstream, spikes need only additions, and only the weights of active inputs are read. Dense: every neuron computed and every weight read, as a GPU or a standard transformer does. 45 nm figures (Horowitz, ISSCC 2014): multiply–add 4.6 pJ, add 0.9 pJ, weight read from on-chip memory 2.5 pJ, from off-chip DRAM 320 pJ; the attention cache and the memory state are charged the same in both. An estimate for neuromorphic hardware, not a GPU measurement.

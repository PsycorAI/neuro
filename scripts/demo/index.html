Measured with the GPU's own power sensor (instant power, sampled 50 times a second in a separate process; checked against a wall power meter). “This answer” = reading the prompt + writing the reply, including the GPU's idle power; drawing the brain view on this page is measured separately and not counted. The per-word bars and the curve: both models generating in the same test harness on this GPU, one word at a time (no table for this GPU yet). A standard transformer keeps every earlier word in its attention cache, so its cost per word grows with the conversation; v4's attention window and memory state stay the same size. Today's GPUs compute every weight densely; event-driven hardware would skip the silent neurons (see Future hardware).

Future hardwareESTIMATED

On event-driven (neuromorphic) hardware a silent neuron costs nothing: only the weights of active inputs are read and spikes need only additions. This page estimates the energy of every word the model has processed in this conversation on such a chip, against the v4f transformer computed densely on the same hardware model with the same figures. Memory traffic is included, which is where most of the energy goes; computation alone is shown separately, and is not the headline.

Per word, every layer is counted. Event-driven v4: a silent neuron costs nothing downstream, spikes need only additions, and only the weights of active inputs are read. v4f: every weight read and multiplied, and attention over every earlier word of the conversation. 45 nm figures (Horowitz, ISSCC 2014): multiply–add 4.6 pJ, add 0.9 pJ, weight read from on-chip memory 2.5 pJ, from off-chip DRAM 320 pJ; the attention cache and the memory state are charged as on-chip reads in both models. An estimate for neuromorphic hardware, not a measurement. Critiques of spiking-network energy claims (memory access dominates; compare against an optimised transformer, not the same network) are why memory is included and v4f is the reference.
